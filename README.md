# ParaHUB Mods Distribution

Official remote catalog and native mod binaries distribution for [ParaHUB](https://github.com/NguUyeenx).

- **Catalog Endpoint:** https://raw.githubusercontent.com/NguUyeenx/parahub-mods/main/catalog.json
- **Supported Games:** Travel Town, Seaside Escape
- **Architecture:** ARM64-v8a (AArch64) ELF64
